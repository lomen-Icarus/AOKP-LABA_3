# bevy-lab01-color-torus

Лабораторная работа №1: инициализация Bevy 0.19 и ECS. Тор меняет цвет по
пробелу и цифрам 1–5, клавиша A включает смену раз в секунду, тор вращается
вокруг Y с учётом времени кадра.

```
cargo run --locked
cargo fmt --check
cargo clippy --locked --all-targets -- -D warnings
cargo test --locked
```
