# bevy-lab02-color-cycle

Лабораторная работа №2: glam, контейнер `Vec` и автоматическая смена цвета
(Rust / Bevy 0.19). Построена на лабораторной №1.

Цвет тора меняется раз в секунду: белый → синий → красный → жёлтый →
фиолетовый → снова белый. Цвета хранятся как `Vec<Vec3>`, секунду отсчитывает
`Timer` в режиме `Repeating`, в консоль выводятся индекс и RGB.

## Запуск

```
cargo run --locked
```

| Клавиша | Действие |
|---|---|
| — | Автоматическая смена цвета раз в секунду |
| Пробел | Следующий цвет, автоматика продолжает работать |
| 1–5 | Прямой выбор цвета |
| L | Плавный переход между цветами |

## Проверка

```
cargo fmt --check
cargo clippy --locked --all-targets -- -D warnings
cargo test --locked
cargo run --locked --example capture   # Linux без экрана: xvfb-run -a cargo run --example capture
```
