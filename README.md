# Лабораторные работы 1–3: Rust / Bevy 0.19

Одна программа, в которой собраны все три лабы. Лабы построены одна на
другой: лаба 2 — доработка лабы 1, лаба 3 использует модель-тор, цвет `Vec3`,
контейнер `Vec` и схему систем «ввод, симуляция, визуализация» из лаб 1 и 2.

## Запуск

```
cargo run --locked
```

Открывается лаба 3. Другие лабы выбираются клавишами прямо в окне:

| Клавиша | Действие |
|---|---|
| F1 | Лаба 1: цвет и вращение тора |
| F2 | Лаба 2: glam, Vec и автоматическая смена цвета |
| F3 | Лаба 3: четыре объекта носиками к центру |
| Tab | Следующая лаба по кругу |

Сразу с нужной лабы: `cargo run --locked -- 1` или `cargo run --locked -- 2`.
Каждая лаба при входе начинается заново, как при отдельном запуске.

| Лаба | Управление |
|---|---|
| 1 | Пробел — следующий цвет, 1–5 — выбор цвета, A — смена раз в секунду |
| 2 | Цвет меняется сам раз в секунду; пробел и 1–5 — вручную, L — плавный переход |
| 3 | R — вращение объектов вокруг центра |

Первая сборка идёт 10–15 минут: Bevy компилируется целиком. Потом запуск
занимает секунды.

## Файлы

| Файл | Назначение |
|---|---|
| `src/main.rs` | Окно, выбор лабы, подключение модулей |
| `src/lab1.rs`, `src/lab2.rs`, `src/lab3.rs` | Код каждой лабы |
| `src/graphic_object.rs` | Модуль GraphicObject из задания лабы 3 |
| `src/labN/tests.rs`, `src/tests.rs` | Автотесты лаб и переключения (24 теста) |
| `examples/capture.rs` | Проход по трём лабам с сохранением кадров |
| `docs/otchet_labNN.docx` | Отчёты |
| `docs/razbor_labNN.md` | Учебные разборы с вопросами для защиты |
| `screenshots/` | Кадры для отчётов |
| `verification.txt` | Результаты проверки |

## Проверка

```
cargo fmt --check
cargo clippy --locked --all-targets -- -D warnings
cargo test --locked
cargo run --locked --example capture   # Linux без экрана: xvfb-run -a cargo run --example capture
```

## Требования

Rust 1.95 или новее. Windows: установщик rustup и Visual Studio Build Tools.
Linux: X11 или XWayland и драйвер Vulkan; на Ubuntu
`sudo apt install mesa-vulkan-drivers libvulkan1 libxkbcommon-x11-0`.
