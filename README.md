# Лабораторные работы: Rust / Bevy 0.19

Все работы — один развивающийся проект: лаба 2 построена на коде лабы 1,
лаба 3 — на лабах 1 и 2.

| Каталог | Работа | Что добавлено к предыдущей |
|---|---|---|
| `lab01/` | № 1. Bevy и ECS: цвет и вращение тора | основа: сцена, тор, палитра, клавиши, вращение |
| `lab02/` | № 2. glam, Vec и автоматическая смена цвета | цвета `Vec<Vec3>`, таймер, системы симуляции и визуализации |
| `lab03/` | № 3. Размещение объектов в сцене | модуль `GraphicObject`, матрица модели, четыре объекта |

Запуск любой работы:

```
cd lab02
cargo run --locked
```

Отчёт каждой работы: `labNN/docs/otchet_labNN.docx`. Проверки: `cargo fmt --check`,
`cargo clippy --locked --all-targets -- -D warnings`, `cargo test --locked`.
Требования: Rust 1.95 или новее; на Linux — X11/XWayland и драйвер Vulkan.
